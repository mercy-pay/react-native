# Contribuer

Merci de votre aide.

- **Un bug ou une idée** : ouvrez un ticket avec ce que vous attendiez, ce qui s'est passé et votre version.
- **Une faille de sécurité** : jamais en ticket public, voir [SECURITY.md](SECURITY.md).
- **Une modification** : ouvrez une pull request avec un test qui la couvre. Lancez `npm test` avant de l'envoyer.

Ce paquet suit l'API Mercy Pay v1. Ses versions suivent [SemVer](https://semver.org/lang/fr/) : rien de cassant sans nouvelle version majeure.
